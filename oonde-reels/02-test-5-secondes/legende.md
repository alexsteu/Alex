# 02 · Le test des 5 secondes — légende

## Légende (prête à coller)

Votre site passe le test des 5 secondes ? Commerces de Lausanne à Vevey.

C’est une vraie méthode de designers : on montre une page 5 secondes, puis on demande ce qu’on a retenu.
Trois réponses doivent sauter aux yeux : ce que vous faites, vos horaires, comment vous joindre.
Faites-le sur votre site, avec un ami qui ne le connaît pas.

Envoyez ce Reel à un commerçant qui n’a pas touché à son site depuis longtemps.
Et si vous voulez voir le vôtre refait : on vous montre votre site avant que vous payiez. Écrivez-nous sur WhatsApp, lien dans la bio.
