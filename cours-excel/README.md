## Aide-mémoire : noms des fonctions anglais → français

Le fichier du cours est en **anglais**. Si ton Excel est en **français**, les noms changent
et le séparateur d'arguments est `;` au lieu de `,`.

| Anglais | Français | Rôle |
|---|---|---|
| `COUNT` | `NB` | Compte les cellules contenant un **nombre** |
| `SUM` | `SOMME` | Additionne |
| `PRODUCT` | `PRODUIT` | Multiplie |
| `AVERAGE` | `MOYENNE` | Moyenne |
| `ROUND` | `ARRONDI` | Arrondi classique (≥ 5 → au-dessus) |
| `ROUNDUP` | `ARRONDI.SUP` | Arrondi toujours vers le haut |
| `ROUNDDOWN` | `ARRONDI.INF` | Arrondi toujours vers le bas (tronque) |
| `MROUND` | `ARRONDI.AU.MULTIPLE` | Arrondi au multiple le plus proche |
| `RAND` | `ALEA` | Décimal aléatoire entre 0 et 1 |
| `RANDBETWEEN` | `ALEA.ENTRE.BORNES` | Entier aléatoire entre 2 bornes |
| `IF` | `SI` | Condition |
